# M Blog 设计规范文档

## 一、项目简介

### 1.1 项目名称
M Blog - 技术博客与工具分享平台

### 1.2 背景与目标
M Blog 是小M用于展示自我、记录思考并分享提效工具的个人博客。公开内容面向所有访客阅读，访客无需注册或登录；只有站点管理员可以登录后台维护内容。

### 1.3 业务边界与不做清单
**在范围内：**
- 技术文章发布与阅读
- 随笔、专题与个人介绍展示
- 工具分享与管理
- 单管理员后台写作和内容管理
- 响应式多端适配

**不在范围内：**
- 访客账号、注册或登录
- 多用户写作与复杂权限系统
- 评论及其他社区互动（当前阶段暂不开放）
- 付费内容
- 社交粉丝系统

### 1.4 关键用户/角色
- 站点管理员：唯一可登录后台、写作并管理内容的角色
- 普通访客：无需账号即可阅读文章、专题与工具内容

### 1.5 当前阶段与里程碑
- **V1.0**: 完成核心 UI 优化与设计系统建设
- **当前阶段**: 完成个人内容发布、管理与公开阅读闭环；评论继续保持关闭

## 三、架构总览

### 3.1 架构风格
- **运行时形态**: 单页应用 (SPA)
- **框架选型**: Vue 3 + TypeScript + Vite
- **UI 框架**: Element Plus
- **状态管理**: Pinia
- **路由管理**: Vue Router

### 3.2 技术决策摘要
- 使用 Vite 作为构建工具，提升开发体验
- 采用 Composition API 进行组件开发
- 集成 Element Plus 组件库加速开发
- 使用 CSS Custom Properties 实现主题切换

### 3.3 系统拓扑图

```mermaid
graph TD
    Client[浏览器客户端]
    CDN[静态资源 CDN]
    API[后端 API 服务]
    DB[(数据库)]
    
    Client -->|HTTP/HTTPS| CDN
    Client -->|HTTP/HTTPS| API
    API --> DB
```

### 3.4 主要组件与职责
- **App.vue**: 按路由元数据分发公开或后台布局
- **PublicLayout.vue**: 公开站点页头、主内容区域与页脚
- **AdminLayout.vue**: 仅管理员可访问的后台壳层
- **features/**: 文章、专题、工具、站点、搜索、媒体及会话页面
- **shared/api/http.ts**: 统一 Fetch、Session、CSRF 和错误响应处理

### 11.2 缓动函数

| 类型 | 效果 | 用法 |
|------|------|------|
| --ease-in-out | 加速后减速 | 元素进出 |
| --ease-out | 快速开始，缓慢结束 | 提示出现 |
| --ease-in | 缓慢开始，快速结束 | 提示消失 |

### 11.3 关键帧动画

```css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```
